在 Windows 上更该先确认的功能

这些都是 Roxi 客户端里能直接看到的设置，用来判断一个客户端装上之后好不好用，而不是只看下载次数。

规则智能分流和全局

首页可在规则·智能分流和全局模式之间切换。日常浏览用规则模式，让国内网站直连；需要整机走代理时再切到全局，减少浏览器和系统设置各管各的情况。

自定义分流与系统代理例外

高级网络设置里可改自定义分流和系统代理例外，避免把本机、局域网或不该走代理的请求一并送出去，也减少退出后系统代理还留在「开」的状态。

一键网络诊断

连不上、只能打开部分网站，或托盘图标显示已连接但实际没网时，先跑一遍网络诊断，再决定是换节点、查 DNS，还是检查本机代理残留。

断网保护

断网保护（kill switch）可在节点突然断开时拦住未加密的直连，适合在公共网络或不稳定的宽带里使用。

常见问题

只能用 v2rayN 吗？官方客户端怎么下？

不必绑定某一个名字。Roxi 自己提供 Windows 安装包，也可把同一份订阅导入其他客户端。备用软件和说明见 Hiddify / v2rayN / Clash Verge 下载页。若更习惯图形界面管理配置，也可对照 GUI.for.Clash 的导入与回退说明。

退出加速器之后，Windows 整个没网怎么办？

先按 Windows 退出代理后恢复联网的顺序 检查系统代理是否还开着，不要先急着重装系统。

任务栏显示「无 Internet」，但浏览器其实能打开网页？

这常常是 NCSI 探测和代理叠加造成的误报。可按 Windows NCSI 探测排查 逐项核对。

会记录我的上网日志吗？

不会。Roxi 采用无日志策略。注册时如需填写邀请码，可以使用 6666。
